# Phantoms AI — Day 1 Task Solution

## عن المشروع
تطبيق عملي لتاسك اليوم الأول. الهدف منه بناء برنامج قسمة تفاعلي ومحمي ضد أخطاء التشغيل (Robust Code) لتفادي انهيار البرنامج أثناء التنفيذ.

## تفاصيل الكود والحل
* **دالة قراءة الأرقام (`read_number`):** تستخدم حلقة تكرار مع التعامل مع الأخطاء (`try-except`) للتأكد من أن المدخلات أرقام صحيحة أو عشرية (`float`) ومنع إدخال النصوص أو الحروف.
* **دالة القسمة (`divide`):** دالة أساسية لتجرد عملية القسمة لضمان إعادة استخدام الكود.
* **إدارة الأخطاء (`ZeroDivisionError`):** معالجة القسمة على صفر لمنع انهيار البرنامج وإظهار رسالة توضيحية للمستخدم.

## المفاهيم التي تم تطبيقها
* Python Functions & Return Values
* Data Type Casting (float)
* Exception Handling (try / except)
* Specific Exceptions Handling (`ValueError`, `ZeroDivisionError`)
